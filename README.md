CryptoPixel v1.2 — Windows 桌面像素行情窗

一、第一次启动
1. 把 ZIP 完整解压到普通文件夹，例如 D:\CryptoPixel，不要直接在压缩包内运行。
2. 需要 Windows 10/11 与 Python 3.11 或更新版本（包含 Tcl/Tk）。
   如果电脑已装 Python，直接进行下一步。
   没安装请到 https://www.python.org/downloads/windows/ 安装，勾选 Add Python to PATH。
3. 双击 START.bat。首次会在当前文件夹建立独立 .venv 环境并安装 websocket-client。
   这一步需要联网；以后启动不重复安装，不需要管理员权限。
4. 出现窗口后，可关闭其他终端；窗口本身会持续接收行情。
5. 右键 START.bat → 发送到桌面快捷方式，以后从桌面双击。

二、界面与操作（v1.2）
默认无边框、横向紧凑布局，只显示币种和价格，没有标题、USDT、时间或状态栏。
全部价格仍为 Binance 现货 USDT 报价，统一显示两位小数。
按住窗口任意位置拖动；在窗口内点击鼠标右键，打开全部设置。

显示布局：
- 横向紧凑：币种在上、价格在下，按价格宽度自动收紧，高度 56 像素；币种与价格居中。
- 横向单行：币种和价格同一行，按内容自动收紧，高度 36 像素。
- 竖向排列：三个币上下排列，按最长价格确定宽度，高度 168 像素；每组居中。
大小可选 80%、100%、125%、150%；系统高 DPI 环境实际显示效果可能不同。
数字使用等宽点阵，普通涨跌不会改变窗口大小；仅价格位数变化或首次收到报价时重新计算宽度。
自动去除末尾多余字距，统一外边距和币种组间距；超长价格会缩小以容纳。

右键菜单还可切换无边框、置顶、刷新模式、查看连接状态、重连或退出。
F2 切换边框；Esc 恢复系统标题栏；Alt+F4 退出。
无边框模式可能没有任务栏入口，需要最小化时先按 Esc 恢复标题栏。
快捷键需窗口有焦点（先点一下窗口）；设置会自动保存。
所有模式主窗口只显示币种和价格；未知价格显示横杠，断线或过期时变暗。
右键“连接状态”可查看详细信息，主窗口不额外显示提示文字。

三、刷新速度和资源
默认均衡模式：三个 miniTicker 共用一条 WebSocket 连接，服务端约 1 秒更新。
界面每 500ms 检查最新值，只有显示值变化才重新绘制数字。
极速模式：使用 aggTrade 实时聚合成交推送，界面每 250ms 合并显示最新价格。
250ms 是界面刷新上限，不是交易所推送频率或端到端延迟承诺。
极速模式成交活跃时消息量明显更大；日常常驻建议均衡模式。
只保留每个币最新一条报价，不累积成交历史；无浏览器内核、动态图表或轮询 REST 请求。
最小化后界面更新降为每秒一次，网络仍维持所选模式以便恢复窗口时显示最新数据。
实际 CPU、内存、流量会随 Windows、Python 版本和市场活跃度变化，未给出实测占用承诺。

四、断线与异常
断线保留最后报价并变暗，不用演示数据冒充行情。
某币超过 10 秒未收新数据，或数据源事件时间落后超过 10 秒，将币种和价格变暗。
最后接收报价时间只在右键“连接状态”中查看。
本机系统时间明显不准也可能触发过期提示，请同步 Windows 时间。
20 秒无有效行情将重连；失败时逐步退避，最长约 31 秒再试。
程序交替尝试 Binance 两个官方市场数据域名，均为同一交易所，并非备用交易所。
当地网络需要能连接行情服务；若两者均不可达，程序不会显示实时价格。
无需交易所账号、API Key 或钱包，不执行任何交易。

启动失败：双击 DEBUG.bat，保留错误信息，或查看
%LOCALAPPDATA%\CryptoPixel\app.log
日志滚动限制为 3 份，每份约 200KB；不记录价格流水。
偏好设置在同文件夹 settings.json。删除该文件可重置偏好。

五、生成不用安装 Python 的独立 EXE（可选）
当前交付包是源码启动版，不含已编译的 Windows EXE。
1. 先成功运行 START.bat，再关闭行情窗口。
2. 双击 BUILD_EXE.bat，首次会联网安装 PyInstaller。
3. 生成成功后，dist\CryptoPixel.exe 可单独复制到桌面或同架构 Windows 电脑运行。
4. 生成 EXE 后运行无需 Python，也不需要上架 Microsoft Store。
这是本地生成的未签名程序；未在当前 Linux 制作环境中执行 Windows 打包或实机验收。

当前制作环境无法进行 Windows 桌面实机测试，也无法验证当地网络的实时行情连通性。

七、从 v1.0 更新
关闭旧程序，将新版完整解压后运行 START.bat。
首次升级默认使用横向紧凑和无边框，并保留原有刷新模式和置顶偏好。
如果以前生成过 EXE，需要使用新版 BUILD_EXE.bat 重新生成。

保留绿色点阵风格，无需调用苹方；不依赖本机字体安装。
横向布局改为按各自价格实际宽度分配空间，去除最右侧固定空白；币种在价格上方居中。
已运行源码逻辑和绘图边界检查；未在 Windows 实机验收。
升级时先退出旧程序，重新解压并运行 START.bat；如果使用 EXE，需要重新运行 BUILD_EXE.bat。
